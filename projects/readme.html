Project

Readme

Readme is a chair made from library books that were about to be thrown away.

Made by
Merlijn Lewerissa
Client
DOK Library Delft, NBD Biblion
With
Delft University of Technology
Year
2021
Type
Furniture

Every year Dutch libraries discard more than 900,000 books that are too old or have been on the shelves too long. Their plasticised covers and lending chips make them hard to recycle, and most solutions only look at the material, not at the stories inside.

Made with NBD Biblion, which produces the books for Dutch libraries, and DOK Library Delft, Readme holds books in belts on a steel frame, so covers and pages become the seat and the back. The NFC chips in the covers link each chair to a digital profile of the books it contains and how often they were read, so people can find a chair that suits them.
